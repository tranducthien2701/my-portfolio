## 🎯 Mục Tiêu Nghề Nghiệp

Tận dụng nền tảng vững chắc về kiến trúc hạ tầng mạng Cisco và năng lực phân tích an ninh mạng để vận hành, bảo vệ các hệ thống doanh nghiệp trọng yếu. Mục tiêu ngắn hạn của tôi là cống hiến tại các vị trí Kỹ sư An ninh mạng / SOC Analyst, đồng thời phát triển kỹ năng lập trình tự động hóa để hướng tới vai trò chuyên gia **DevSecOps**.

## 🛠️ Kỹ Năng Nổi Bật

*   **Network Engineering:** Cấu hình hạ tầng mạng chuẩn doanh nghiệp, Cisco Packet Tracer, OSPF Routing, VLAN, Site-to-Site VPN, High Availability (HSRP).
*   **Cybersecurity:** Giám sát an ninh, thiết lập luật cảnh báo (Rule-based alerting), phân tích log (Windows Event Logs), phát hiện đe dọa.
*   **Fullstack Development:** FastAPI, React, WebSockets, PHP MVC, JavaScript, Python, PostgreSQL.

## 🚀 Các Dự Án Tiêu Biểu

1.  **Enterprise Security Monitoring Dashboard (Mini-SIEM):** Hệ thống Full-stack (FastAPI & React) thu thập, phân tích log và hiển thị cảnh báo an ninh thời gian thực qua WebSockets.
2.  **Enterprise Network Design & Simulation:** Thiết kế, giả lập hạ tầng mạng 3 lớp chuẩn doanh nghiệp với các vùng mạng nghiêm ngặt và tính sẵn sàng cao.
3.  **Cloud-Arena E-commerce Platform:** Nền tảng thương mại điện tử sử dụng kiến trúc PHP MVC với hệ thống quản trị chặt chẽ và kiểm định dữ liệu an toàn.
